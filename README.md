# セッションタイマー

タイマーとストップウォッチのアプリです。ブラウザで開くだけで使えます。

- 題名つきのセッションを作り、「5分・5分・10分」のように区間を並べられる（1秒単位で設定可）
- 各区間の終了1分前と終了時に音声でお知らせ
- タイマー・ストップウォッチともにカウントダウン／カウントアップを切り替え可能
- アラーム：時刻と題名を登録（1分前と時刻ちょうどに音声でお知らせ／ページを開いている間だけ鳴ります）
- 区間ごとに「指示」（例：ノートにまとめる）を書くと、大画面と小窓に大きく表示
- 大画面では各区間の開始〜終了時刻（見通し）と「つぎ」を表示
- 「小窓」：授業中も画面の端に小さく出しておけるミニ表示（Chrome / Edge では常に手前に表示）
- 「わたしの声」：残り1分・区間の切りかえ・終了などのお知らせを先生の声で録音して流せる（録音はそのブラウザの中だけに保存）
- A−／A＋で表示サイズを変更、「大画面」で電子黒板向けの表示

`index.html` をダウンロードしてダブルクリックしても使えます。

## 都道府県ベースボール

`todofuken-baseball/` フォルダに、野球で都道府県をおぼえるクイズゲームがあります。

- 出題：プロ野球12球団、選手の出身地、メジャーリーガーの道のり、高校野球（47都道府県・各5校以上）、名産
- 野球なしの設定：白地図・形・県庁所在地・読みがな・何地方？・名産
- れんしゅうモード（10問・タイム記録）：白地図クイズ、地図タップ、形から名前、名前から形、県庁所在地、読みがな、何地方？、名産、ミックス
- モード：日本一周、フリー、東日本、西日本、地方別（北海道・東北／関東／中部／近畿／中国／四国／九州・沖縄）
- 甲子園しりょう：高校名一覧、夏の出場回数ランキング、優勝回数ランキング
- セーブは名前つきで5人分、考えた時間の記録とグラフ（ブラウザに保存）
- 字体：BIZ UDPゴシック
- 地図：地球地図日本（国土地理院）をもとに作成
